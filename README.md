# ToolAtlas — privacy policy

The public privacy policy for the ToolAtlas iOS app, served by GitHub Pages at
<https://jr-design.github.io/toolatlas-privacy/>.

It lives in its own public repository because the app's own repository is
private, and GitHub Pages needs a public one on the free plan.

## Keeping it honest

Apple requires this URL for TestFlight and App Store review, but the reason to
keep it accurate is simpler: it describes what the app actually does, and the
app is a record people expect to still be true years later.

**Update this page in the same change as any code that alters what leaves the
device** — a new third-party service, a new field synced to the server, or
anything that starts collecting what the app currently doesn't. The policy
currently claims there is no analytics or tracking of any kind, which is true;
adding any would make this page a lie.

The same text is shown inside the app at Profile → Account → Privacy & data, so
change both together.
